# Sarcasm Detection in Social Media Text

## Overview

This project investigates automatic sarcasm detection across multiple text domains using classical machine learning and deep learning approaches.

## Research Questions

**RQ1 — In-Domain Performance**
How effectively can different NLP models detect sarcasm in short informal text?

**RQ2 — Effect of Context**
Does incorporating contextual information improve sarcasm detection performance?

**RQ3 — Cross-Domain Generalisation**
How well do sarcasm detection models generalise across domains when trained on one dataset and evaluated on another?

## Datasets

- **News Headlines** — journalistic sarcasm (Misra & Arora, 2023)
- **Reddit SARC** — conversational social media sarcasm (Khodak et al., 2018)
- **SemEval 2018 Task 3** — Twitter irony detection
